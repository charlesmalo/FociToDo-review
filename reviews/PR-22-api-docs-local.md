## Automated review output

Scope of PR #22 (4 commits, 28 files, +838/-86): `/api/docs` and `/api/openapi.json` removed from the API (`docsRoutes.ts` deleted), `docs/api/index.html` generated from `apps/api/openapi.json` by `packages/diagrams/src/apiDocs.ts`, `.gitattributes`, ADR 0016, and the plans for this and the following deadlines PR.

**The change**:
- The API no longer registers the explorer or the document routes, so both paths fall through to the API's own `404` problem response.
- `docs/api/index.html` is a single file with Swagger UI's script and style and the OpenAPI document inlined; it is regenerated by `packages/diagrams/src/apiDocs.ts` and checked by the test gate (`packages/diagrams/tests/apiDocs.test.ts`).
- Because a file opened from `file://` cannot resolve `#/components/...` references, `packages/diagrams/src/inlineRefs.ts` dereferences the document first (local JSON-pointer refs, escapes, sibling keys override, cycle guard, throws on an unresolvable ref).
